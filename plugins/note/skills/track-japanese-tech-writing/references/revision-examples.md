# 日本語の推敲例

不自然な箇所の直し方に迷った場合に、該当する例だけを使う。
表現を見つけただけで直す必要はない。資料の意味と、その場で表現が果たす役割を先に確かめる。

## 留保と否定を保つ

「提示し続けているかもしれない」を「提示し続けている」に変えると、可能性が事実になる。
文を整えるなら「提示し続けている可能性がある」のように、未確定であることを残す。
「Aが原因ではないとは言い切れない」も、「Aが原因だ」と断定せず、原因である可能性を排除できないと書く。

## 名詞の連なりを開く

「作業時間短縮率を測っていない」は「作業時間がどれだけ短くなるかは測っていない」と言い換えられる。
文字数は増えても語の関係が読み取りやすくなる。
測定値を補ったり、未測定という条件を消したりしない。

## 翻訳調と曖昧な比喩を直す

| 元の表現 | 確かめること・修正例 |
| --- | --- |
| 情報がこの層に住んでいる | 含まれるのか、保存されるのかを資料から確認して動詞を選ぶ |
| 問いが開かれている | 未解決を指すなら「問いは未解決である」 |
| 選好を運ぶ | 関係に応じて「選好を表す」「選好が反映される」 |
| モデルが文体を知っている | 観察したのが出力の一貫性なら、その事実を書く |
| この手法が効く | 何がどの条件で変わるかを、確認した範囲で書く |
| 知識を体に入れる | 通常の習得なら「身につく」 |

実際の機能名や定着した用語まで、語だけを見て置き換えない。

## 情報を足さない表現を見分ける

次の表現は検索の手がかりになる。使用の有無で採点せず、削って失われる意味があるか確認する。

- 予告と総括: 「重要なのは」「本章では〜を扱う」「まとめると」「〜に他ならない」。
- 姿勢だけの宣言: 「正面から扱う」「正面から回収する」。
- 内容のない評価: 「不可欠」「核心的」「鍵となる」「多角的」「包括的」「堅牢」。
- 動作を特定しない語: 「深掘りする」「言語化する」「触れる」。
- 接続や強調の反復: 「〜において」「〜の観点から」「さらに」「非常に」。

「多角的に分析すると、重要なのは、入力元によって検証の順序を変えることである」は、
「入力元によって検証の順序を変える」で主張が伝わる。
一方、「再送の冪等キーがある」という機構を説明した文は、評価語を含んでも根拠を削らない。

## 削除で論理を失わない

同じ事例を扱う二文でも、一方が条件や例外を加えていれば重複ではない。
「しかし一方で」などの接続も、論理関係や必要なリズムを伝えているなら残す。
削ったあとに話が飛ぶ場合は、必要な説明を戻すか、対象と関係を具体的に書き直す。
