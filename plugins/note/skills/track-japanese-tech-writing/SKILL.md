# 日本語の文章規範

読者が文の意味と論理関係を順に理解できる文章にする。
短文化や表現の置換によって、元の主張を強めたり、必要な前提を失ったりしない。
ユーザーの用途と文体指定を優先し、小さな修正では関係する観点だけを使う。

## 用途に応じて参照する規範

- レポート全体の構成を作る場合は [レポートの構成](../track-japanese-report-readability/SKILL.md) を使う。結論を出す順序はそちらで決める。
- 通読する解説の緩急を調整する場合だけ [読み物の緩急](../track-cognitive-rhythm-writing/SKILL.md) を使う。レポートには適用しない。
- track ノートの日本語本文を新規執筆・整形する場合は [本文の表記](../track-markdown/references/PROSE_STYLE.md) を読む。保存手順や Markdown 構文全体を、このスキルのためだけに読む必要はない。
- 不自然な表現の直し方に迷った場合は [推敲例](references/revision-examples.md) の該当項目だけを参照する。

## 意味と確信度を保つ

- 事実、推定、可能性、仮定、読者の疑念を区別する。「かもしれない」「だろう」などは、根拠なく主張を弱める場合だけ削る。確定していない命題を断定に変えない。
- 否定する命題と、否定・条件・例外のかかる範囲を特定する。二重否定を直すときも、可能性の留保を確定的な肯定に変えない。
- 測っていない数値や効果、確認していない経験を足さない。「有効」を「必須」にするなど、語調だけで主張を強めない。
- 別々の原因や決定を「同じ」とまとめない。複数の要因があるなら切り分け、例が主張の一部しか支えない場合は主張の範囲を狭める。
- 因果を述べるなら、なぜそうなるかを示す。検出、保証、解決の成否は、成立する条件とともに書く。
- 章や節をまたいでも、分類、定義、用語の指す対象を揃える。

## 主述と修飾の関係を明らかにする

主語が何をし、どの条件で述語が成り立つかを先に確認する。
主述が離れた文、修飾先が二通りに読める文、否定や条件が入れ子になった文を重点的に読む。
文を分ける場合も、因果、対比、条件の関係が残るようにする。

- 長い修飾を独立した文にするか、修飾先の近くへ動かす。読点は意味の切れ目に置き、個数だけで増減しない。
- 名詞が連なって動作を読み取りにくい場合は、誰が何をするかを動詞で書く。主体を資料から特定できなければ、推測で補わない。
- 「これ」「この例」などの指示先を明らかにする。図、表、コードが別の例を示す場合は、同じ対象のように扱わない。
- 対比する定義は述語の型を揃える。既出の説明への参照は文頭に置き、定義を「〜と説明した」の中に埋め込まない。
- 方式を置き換える説明では、やめる方式から採る方式へ書く。同じ主語は、他方の対象と混同しない範囲で省略できる。

文字数は点検のきっかけにとどめる。
必要な説明を足して長くなった文を、長さだけで元へ戻さない。

## 用語と前提を順に導入する

- 新しい概念は、何の一種なのかと、どの働きや性質を持つかを示す。読者が名前だけを保持したまま定義を待つ構成を避ける。
- 節の中心語や上位概念は、対象範囲とまとめる理由を示してから使う。導入後は同じ語を使い、曖昧な「AI」「ツール」などへ戻らない。
- 専門用語や訳語はその分野の慣用に従う。一般的な動作に専門語の響きだけを借りない。
- 後で参照しないファイル名や識別子は、理解に必要な役割名で示す。新しい例を足す場合は、前の例との違いと必要性を伝える。
- 導入に過剰な詳細を詰め込まない。説明を削ったら、残る文の前提や参照先が失われていないか確認する。

## 段落で論を進める

一段落は一つの話題とし、最初の文で何の話かを伝える。
段落間の因果や対比が内容だけで伝わらない場合は接続表現を使う。段落ごとに接続詞を足す必要はない。

- 反論や譲歩を置いたら、根拠を示して論を進める。後で訂正する診断を、一度著者の声で事実として断定しない。必要なら読者や通説の見方として示す。
- 誤解を訂正するときは、否定する命題を具体的に示し、否定の根拠を書く。強調のためだけに「AではなくB」を繰り返さない。
- 読者の実際の疑問は問いとして示してよい。架空の読者の反応を演じて一語で答える問答や、著者の立場の弁明を足さない。
- 前方参照は論証が一段落した位置に置く。そこで扱うと書いた論点は実際に回収する。
- 見出しは、その節の問いや対象を特定できるものにする。名詞句、疑問形、結論を示す形のいずれも、文書の用途に合わせて選ぶ。

## 不自然な表現と重複を削る

「重要なのは」「多角的に」「〜と言えるだろう」などの表現は、その文が情報を足しているかで判断する。
本文で定義した術語、意味のある留保、必要な反復まで単語で一律に禁止しない。

- 根拠のない評価や強調は、確認した動作、機構、条件に置き換える。内容を特定できなければ削るか、資料を確認する。
- 英語慣用句の直訳、抽象物の擬人化、ひねった比喩は、実際の主体と動作で述べ直す。定着した専門用語や無生物主語を一律に排除しない。
- 書く予定や直前の内容を言い換えるだけの文を省く。同じ結論でも条件、例外、含意を加える文は残す。
- 隣接する節の役割が重なるなら統合する。並列項目で対象や位置づけを揃えるための反復は、主張の重複と区別する。
- 接続詞や短い括弧補足は、因果、対比、対象の特定に必要なら残す。文字数や出現回数だけで削らない。
- 短い決め台詞や、危険を煽る帰結の列挙で強調しない。例の動作は行為者を明らかにし、資料にない人物設定や体験を足さない。

短くするのは、対象、動作、因果、条件を順に読んで理解できる場合に限る。
短い文に整えただけで、空虚な評価や進行予告が残ることもある。書き換えた文にも同じ点検を行う。

## 推敲後の確認

1. 原文や資料と比べ、事実、確信度、否定の向き、条件、出典を保っているか。
2. 主述、修飾先、指示先が明らかで、前提から順に理解できるか。
3. 削った文が持っていた根拠や例外を、読者の推測に任せていないか。

lint を使う場合も、指摘は確認候補として扱う。
必要な引用、定義、出典の反復を指摘件数のために変えず、指摘がなくても意味と論理関係を点検する。
